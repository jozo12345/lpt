You are converting a mosque prayer timetable (attached as an image or PDF) into plain text for my prayer-times website.

1. Work out the mosque's name and which month or months (and year) the timetable covers. A sheet can cover one month, several months or a whole year. Write one block per month.
2. Choose the block type:
   - East London Mosque or London Prayer Times: TYPE: start, with the start ("begins") times.
   - Any other mosque: TYPE: jamaah, with the jamā'ah / iqāmah / congregation times.
3. Reply with only the blocks, inside one code block. No other text.

Jamā'ah block:
MOSQUE: <mosque name as printed>
TYPE: jamaah
MONTH: <YYYY-MM>
JUMUAH: <Friday khutbah or Jumu'ah time as HH:MM, or - if not stated>
DAY FAJR DHUHR ASR MAGHRIB ISHA
01 06:00 13:30 16:15 18:31 20:30
02 ...

Start-time block (East London Mosque / London Prayer Times only):
MOSQUE: East London Mosque
TYPE: start
MONTH: <YYYY-MM>
DAY FAJR SUNRISE DHUHR ASR MAGHRIB ISHA
01 05:30 06:58 12:55 15:56 18:42 20:00
02 ...

Rules:
- Every time in 24-hour HH:MM. Timetables often leave out am/pm: Fajr and sunrise are in the morning, Dhuhr is around midday (11:00 to 13:59), and Asr, Maghrib and Isha are afternoon or evening, so 4:30 means 16:30.
- One line per day, starting at 01, covering every day of the month in order.
- If only one Maghrib time is shown (prayed at sunset), use that time.
- For Asr start times, use the earlier (first / 1 Mithl / Shafi'i) time.
- On Fridays, give the Jumu'ah time in the DHUHR column if the sheet shows one for that day.
- Copy times exactly as printed, including the clock-change days. Never estimate or calculate a missing time: write - instead.
- Before replying, check every line has the right number of times and that the times increase through each day.
